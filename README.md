# IGotYou

纯记忆证明的兜底密码库：把全部账号密码存进一个加密保险柜，靠盲输命中若干条自己记得的口令打开，找回忘记的所有内容。本地存储、无云、无账号。

Flutter 双端（Android + iOS）单代码库，跨端逻辑一致。

## 核心特性

- **多口令解锁**：Shamir 秘密共享把主密钥切成 N 份，每份由一把"钥匙口令"加密，命中 K 个不同口令即打开（N 中 K）。
- **盲输防探测**：解锁页不显示列表、不显示命中数、不显示命中反馈，只有输入框与机会/冷却；最后一步（差 1 个正确值）按钮金色高亮"解锁"，人工点击才打开（两段式）。
- **冷却机制**：一轮机会耗尽进入冷却，时长按可配置序列无限增长。
- **全量加密**：条目（名称、加密密钥、内容）与配置全部 AES-256-GCM 加密于单一 `.igotyou` 文件，可导出备份、异地导入。
- **可选二次加密**：单条目可加锁——`secret`/`note` 独立 AES-GCM 二次加密，查看需输入该条目自己的密钥；可同时作为解锁钥匙。
- **维护层与条目层解耦（方案三）**：改 K / 改 M / 增删钥匙等结构操作不再索要各条目密钥——二次加密条目的口令封套随库加密存储，解锁后即可维护，无需重复输入。
- **错误份额自愈**：历史版本遗留的坏份额，解锁时用 MK 验证自动识别，静默多收口令完成修复，无需用户干预。
- **全局上锁按钮**：盖在所有页面之上、位置恒定，任何页面一键锁定并清空内存密钥。
- **黑金主题**：全局设计 token 唯一来源（`lib/theme/tokens.dart`），零硬编码样式。
